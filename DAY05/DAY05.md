# DAY05 - UDP와 전송 방식 선택

## UDP 실습 결과

- UdpReceiverLab / UdpSenderLab에서 POSITION:3,5 송수신 성공
- UdpPeerLab에서 A와 B의 양방향 UDP 통신 성공
- 위치 메시지 송수신 및 전송/수신 개수 확인 완료

## UDP 전송 확인

UDP의 전송 성공은 로컬에서 데이터그램을 보냈다는 뜻이며,
상대가 실제로 메시지를 받았다는 것을 보장하지 않는다.

## TCP / UDP 선택

- 총알 발사: UDP
  - 실시간성이 중요하고 오래된 정보보다 최신 정보가 중요할 수 있다.

- 친구 요청: TCP
  - 요청이 누락되면 안 되고 정확한 전달이 중요하다.

- 플레이어 위치: UDP
  - 위치는 계속 갱신되므로 이전 위치보다 최신 위치의 빠른 전달이 중요하다.
