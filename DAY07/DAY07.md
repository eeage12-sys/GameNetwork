# DAY07 - 패킷 설계, 보안, 부하 테스트

## 이동 패킷 검증

- MOVE|99|5
  - 결과: ERROR|OUT_OF_RANGE

- MOVE|A|5
  - 결과: ERROR|INVALID_FORMAT

- MOVE|3|5
  - 결과: MOVE_RESULT|3|5

## 부하 테스트

| 요청 수 | 성공 수 | 오류 수 | 총 시간 |
|---|---:|---:|---:|
| 10 | 10 | 0 | 실행 결과 입력 |
| 100 | 100 | 0 | 실행 결과 입력 |

## 보안 설계 메모

- Client가 보내는 값은 그대로 신뢰하지 않고 Server에서 검증한다.
- 비밀번호, 인증 토큰, 개인정보는 평문 패킷으로 보내지 않는다.
- 직접 암호 알고리즘을 만드는 대신 HTTPS/TLS 같은 검증된 보안 연결을 사용한다.
- 인증은 DAY03에서 학습한 HTTPS 로그인 및 토큰 발급 흐름을 사용한다.

## 오늘의 정리

- 숫자 형식과 허용 범위를 Server에서 검사했다.
- 잘못된 요청은 오류 패킷으로 거절했다.
- 부하 테스트는 요청 수, 성공 수, 오류 수, 총 시간으로 기록했다.
