# DAY08 - P2P와 UDP 상태 동기화

## 실습 결과

- POSITION|sequence|x|y 형식 사용
- sequence 번호를 이용해 최신 위치 판단
- sequence가 이전 값보다 크면 최신 위치로 반영
- 같거나 작은 sequence는 오래된 위치로 판단하여 무시
- sequence가 2에서 4로 건너뛸 경우 누락 가능성 표시

## 실행 예

- POSITION|2|4|5
  - 최신 위치 반영

- POSITION|4|6|5
  - sequence 3 누락 가능성 표시
  - 최신 위치 반영

- POSITION|1|3|5
  - 오래된 위치 무시

## 누락된 옛 위치를 다시 요청하지 않아도 되는 상황

실시간 플레이어 위치 동기화에서는 과거 위치보다 최신 위치가 중요하므로,
이미 더 최신 위치를 받았다면 누락된 옛 위치를 다시 받을 필요가 없다.

## 오늘의 정리

UDP/P2P 상태 동기화에서는 모든 메시지를 완벽하게 복구하는 것보다
가장 최신 상태를 유지하는 것이 더 중요할 수 있다.
