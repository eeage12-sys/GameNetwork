# DAY 14: 멀티플레이 테스트 환경과 튜닝

## Host / Client 통합 테스트

테스트 환경

- Unity Editor: Host
- Windows Build: Client
- Scene: NetworkPlay
- 참가 Player 수: 2

| 번호 | 절차 | 기대 결과 | 실제 결과 |
| --- | --- | --- | --- |
| 1 | Host 시작 | Host Player가 생성된다. | 미확인 |
| 2 | Client 연결 | 양쪽에 Player 2개가 보인다. | 미확인 |
| 3 | 코인 획득 | 코인이 양쪽에서 한 번 사라지고 점수가 동기화된다. | 미확인 |
| 4 | Client 종료 | Host에서 Client 종료를 확인하고 남은 Player가 유지된다. | 미확인 |
| 5 | 다시 연결 | 새 Player가 생성되고 현재 공유 상태를 받는다. | 미확인 |
